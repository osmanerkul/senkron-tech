Öne Çıkan Özellikler

Gereksiz servisler olmadan günlük kullanım kararlılığı
Varsayılan & Ön Ayarlar

1. Varsayılan Static White + Özel Renk Seçici

İlk çalıştırmadan itibaren #FFFFFF (100%) sabit beyaz aydınlatma uygular. Sistem tepsisi menüsünden 9 hazır renk ön ayarı (Warm White, Ice Blue, Amber vb.) veya tam RGB ColorDialog seçicisi ile anında renk değiştirip settings.ini dosyasına kaydeder.

Donanım Modları

2. Donanım Efektleri ve Parlaklık Kontrolü

Klavye donanımının yerleşik Static, Breathing, Spectrum Cycle ve Off modlarını destekler; 5 kademeli parlaklık (100%, 75%, 50%, 25%, 10%) ayarı doğrudan donanıma yazılır ve kare döngüsü gerektirmez.

Güç & USB Olayları

3. Modern Standby, Kilit Açma & USB Kurtarma

Windows oturum açılışı (1.5s/4s yeniden deneme), WM_POWERBROADCAST, Modern Standby ekran uyanışı (GUID_CONSOLE_DISPLAY_STATE), SessionUnlock ve WM_DEVICECHANGE (USB tak/çıkar) olaylarını dinleyip aydınlatmayı otomatik yeniler.

Çoklu Monitör & DPI

4. Dikey Görev Çubuğu & Çoklu Ekran Menüsü

Per-Monitor V2 DPI farkındalığı etkinleştirilmiştir. Standart WinForms NotifyIcon'un ikincil ekran sınırından taşmasını önlemek için sağ/sol tıklama menüsü tıklanan monitörün WorkingArea sınırları içine sabitlenir.

Özel İkon & Dinamik Tepsi

5. Çok Çözünürlüklü Tuş Başlığı İkonu

16/32/48/256 px katmanlı özel OrnataLight.ico simgesi .exe içine gömülüdür; sistem tepsisi ikonu ise o an aktif olan LED rengine (veya Spectrum gökkuşağına) göre canlı olarak renklendirilir.

CLI & Otomatik Başlatma

6. Başlangıç Anahtarı & Başsız CLI Modu

Tepsi menüsünden tek tıkla Windows başlangıcına (HKCU\...\Run) eklenip çıkarılabilir. Betik ve zamanlanmış görevler için --test ve --apply-once parametreleriyle tepsi UI açmadan tek seferlik uygulama yapar.

Razer Ornata V3 X HID Protokolü

Klavye neden sıfırlanır ve yönetici yetkisi olmadan nasıl kontrol edilir?

Razer Ornata V3 X donanımında yerleşik profil belleği ve Windows 11 Dynamic Lighting (HID LampArray) arayüzü bulunmaz; bu nedenle güç kesildiğinde aygıt yazılımı fabrika çıkışı gökkuşağı döngüsüne geri döner. Ayrıca Windows, MI_02 kontrol arayüzünü UsagePage=0x0001 / Usage=0x0002 (Mouse) olarak tanıdığı için GENERIC_READ | GENERIC_WRITE erişimine ERROR_ACCESS_DENIED (5) döndürür. OrnataLight aygıtı desiredAccess = 0 ile açarak HidD_SetFeature ve HidD_GetFeature çağrılarını standart kullanıcı yetkisiyle güvenli şekilde gerçekleştirir.

Alan / Bayt Değer Açıklama
MI_02 · FeatureReportByteLength 91 bytes 1 bayt HID Report ID (0x00) + 90 bayt Razer paket yapısı (desiredAccess = 0 ile açılır)
buf[2] · transaction_id 0x1F Ornata V3 X (0x0294) ve Ornata V3 X Rev2 (0x02A2) için işlem kimliği
buf[7..8] · command_class / id 0x0F / 0x04 · 0x0F / 0x02 Extended Matrix parlaklık (0x04) ve efekt (0x02: Static, Breathing, Spectrum, Off) komutları
args[0..1] · storage / led_id 0x01 → 0x00 · 0x05 BACKLIGHT_LED (0x05) hedeflenir; önce VARSTORE (0x01) denenir, yanıt 0x02 değilse NOSTORE (0x00) uygulanır
buf[89] · crc XOR(buf[3..88]) HID Report ID, durum ve ayrılmış bayt hariç tüm payload üzerinde XOR sağlama toplamı

Kurulum & Kaynaktan Derleme

Visual Studio veya SDK gerektirmez — Windows'un yerleşik csc.exe derleyicisini kullanır
1. Klonla ve Derle (Yerleşik .NET Framework 4.x csc.exe) 
git clone https://github.com/osmanerkul/ornata-light.git
cd ornata-light
powershell -ExecutionPolicy Bypass -File .\build.ps1
2. Donanım İletişimini Doğrula (CLI Testi) 
.\OrnataLight.exe --test
Get-Content "$env:APPDATA\OrnataLight\status.log" -Tail 5
3. Başsız Tek Seferlik Uygulama (Betik / Görev Zamanlayıcı) 
.\OrnataLight.exe --apply-once
Windows 11 Sistem Tepsisi (^) Yeni başlatılan tepsi ikonları ilk açılışta saat yanındaki ^ taşma menüsünde yer alır; görev çubuğuna sürükleyerek sabitleyebilirsiniz.
Ayar & Durum Dosyaları Renk, mod ve parlaklık %APPDATA%\OrnataLight\settings.ini dosyasında saklanır; son 50 donanım yanıtı status.log içine yazılır.
Çakışan Yazılımları Kaldırın OrnataLight çalıştıktan sonra Razer Synapse veya OpenRGB servislerini kaldırabilirsiniz; hiçbir ek arka plan aracı gerekmez.
